
# IndustrialCraft 2 重构项目

## 关于

本项目基于 IndustrialCraft 2 的构建版本 `2.8.222-ex112` 进行反编译、重构与升级。

注意：所有分支的 Gradle 版本均为 `9.5.1`, 请注意 Java 版本。
