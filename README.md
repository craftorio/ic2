
# IndustrialCraft 2 重构项目

## 关于

本项目基于 IndustrialCraft 2 的构建版本 `2.8.222-ex112` 进行反编译、重构与升级。

注意：所有分支的 Gradle 版本均为 `9.5.1`, 请注意 Java 版本。

## Branches

- `main`
- `forge
  - `forge/1.12.2` 原版代码, 反混淆, 简单修复
  - `forge/1.16.5` 升级到 1.16.5, 修复部分已知问题（未完成）
  - `forge/1.16.5-old` 已弃用
  - `forge/1.20.1` 已弃用
  - `forge/1.20.1-flatten` 资源文件扁平化版本的分支
